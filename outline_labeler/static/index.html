Keys and mouse

Label
1…0 or the class key
give the selection that class; with nothing selected, choose the brush class
Del
make the selection unlabelled
Ctrl+A
select the whole image (with protect on, a class key then fills only what is unlabelled)
Esc
clear the selection, polygon or smart points
Tools
V
pieces: click a piece, shift+click to add or remove, drag to brush over several
B / E
brush / eraser; [ ] size
P
polygon: click corners or drag freehand; close on the first point, double-click or Enter; Backspace removes the last corner
S
smart click: click inside an object; right-click outside it to trim
View
wheel
zoom
right-drag, middle-drag, Space+drag
move around
=
fit the image
H (hold) / L
peek at the bare image / labels on or off
O
piece outlines on or off
Images
Enter
mark done and go to the next image
, / .
previous / next image
Ctrl+Z / Ctrl+Shift+Z
undo / redo

Everything is saved as you go. Pixels you leave unlabelled are exported as 0.
